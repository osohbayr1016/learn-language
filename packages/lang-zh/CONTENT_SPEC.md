# CONTENT_SPEC — Хятад хэлний сургалтын контентын стандарт (`packages/lang-zh`)

> **Энэ файл бол ганц эх сурвалж (single source of truth).** Контент бичиж байгаа бүх агент
> ажлаа эхлэхээсээ өмнө энэ файлыг бүрэн уншина. Энд заасан талбарын нэр, утгын хэлбэрийг
> **яг** дагана. Нэмэлт талбар зохиож болохгүй; дутуу орхиж болохгүй.

---

## 0. Хамрах хүрээ ба зорилго

Монгол хэлтэй хүн **тэг мэдлэгээс** эхлээд асуулт асуухгүйгээр, өөрөө бие даан хятад хэл
сурах бүрэн систем. Тайлбар, орчуулга, зөвлөгөө, алдааны сануулга — **бүгд монгол хэл дээр
(кирилл)**. Хятад талын өгөгдөл (ханз, пиньинь) л хятадаар.

Уншигч бол:
- хятад хэлний ямар ч мэдлэггүй,
- багштай биш, дан ганц энэ вэбийг ашиглаж байгаа,
- "яагаад" гэдгийг мэдэхгүй бол сэдэл нь тасардаг.

Тиймээс **юуг** заахаас гадна **яагаад одоо, яагаад ийм дарааллаар** гэдгийг үргэлж бичнэ.

## 2. Ерөнхий дүрэм (бүх файлд хамаарна)

1. **Кодчилол:** UTF-8, BOM-гүй. Файл бүр нэг JSON объект, `{"meta": {...}, "items": [...]}` хэлбэртэй.
2. **Хялбаршуулсан ханз (简体)** үндсэн. Уламжлалт хэлбэр (繁體) өөр бол `trad` талбарт.
3. **Пиньиныг зөвхөн тоон хэлбэрээр бич:** `ni3 hao3`, `zhong1 guo2`, `ma5` (5 = хөнгөн аялга).
   - Аялгууны тэмдэгтэй пиньинь (`nǐ hǎo`), монгол галиг, аялгууны массивыг **build script
     автоматаар үүсгэнэ**. Агент гараар бичих ёсгүй. `ü` үсгийг `v` гэж бич: `nv3` (女), `lv4` (绿).
   - Үг доторх үеийг **зайгаар** тусгаана: `pu3 tong1 hua4`.
4. **Монгол орчуулга нь жинхэнэ монгол хэл байх ёстой.** Google-маягийн шууд орчуулга,
   орос/англи хэлний бүтцийг чирсэн өгүүлбэр хориотой. Ярианы байгалийн монгол хэл.
5. **Нэр томьёо** (заавал энэ хувилбарыг ашиглана):
   | Ойлголт | Монголоор |
   |---|---|
   | 汉字 | ханз |
   | 拼音 | пиньинь |
   | 声调 | аялгуу |
   | 偏旁/部首 | түлхүүр (радикал) |
   | 笔画 | зураас |
   | 笔顺 | зураасын дараалал |
   | 量词 | тоолуур үг |
   | 语法 | хэл зүй |
   | 声调变调 | аялгууны хувирал |
   | 轻声 | хөнгөн аялгуу |
   | 儿化 | эр-жих (эрхүү дуудлага) |
6. **Аялгууг үргэлж чухалчил.** Аялгуу бол монгол хүнд хамгийн хэцүү зүйл. Ханз/үг бүрийн
   аялгууг тодорхой заана; андуурч болзошгүй хос үг (妈/马, 买/卖) байвал `confusables`-д бич.
7. **Хэлний ялгааг заа.** Монгол хэлэнд байхгүй авиа, байхгүй бүтэц гарвал `mnContrast`
   талбарт "монголоор яаж боддог вэ, хятадаар яагаад тэгэхгүй вэ" гэдгийг тайлбарла.
8. **Хуурамч мэдээлэл хориотой.** Эргэлзвэл тухайн зүйлийг орхи. Бодит хэрэглээнд байдаг
   үг, өгүүлбэр л оруул.

**Үгийн шаардлага:**
- `examples` — HSK 1–4 бол **2 өгүүлбэр**, HSK 5–6 бол **дор хаяж 1**. Өгүүлбэр нь тухайн
  түвшин болон түүнээс доош түвшний үг л агуулна (шинэ үг оруулах бол `note`-д тайлбарла).
- `usageMn` — хэзээ, ямар нөхцөлд хэрэглэхийг бодитоор бич. "гэсэн утгатай" гэж давтаж
  бичихгүй. Ижил утгатай үгнээс юугаараа ялгаатай вэ гэдгийг заа (жишээ нь 会/能/可以).
- Нэр үг бол `measureWord`-ийг **заавал** бөглө (тоолуур үггүй нэр үг бараг байхгүй).
- Үйл үг бол салангид үйл үг (离合词, ж: 睡觉) эсэхийг `usageMn`-д дурдана.

### 3.8 Аялгууны тэмдэглэгээ

`pinyinNum` дэх тоо: `1` тэгш өндөр, `2` өгсөх, `3` буугаад өгсөх, `4` уруудах, `5` хөнгөн аялгуу.
`ü` = `v`. Цэг таслалыг үеэс тусад нь зайгаар бич: `ni3 hao3 , wo3 shi4 xue2 sheng1 .`

### 3.9 `pos` (үгийн аймаг) — зөвшөөрөгдсөн утга

`нэр үг`, `үйл үг`, `тэмдэг нэр`, `тоо`, `тоолуур үг`, `төлөөний үг`, `дайвар үг`,
`угтвар үг`, `холбоос`, `бөөм`, `аялга үг`, `мэндчилгээ`, `тогтвортой хэллэг`, `дагавар`, `угтвар`

## 4. Чанарын хяналт (өөрөө шалгах)

Файлаа хадгалахын өмнө:

- [ ] JSON бүрэн зөв (`JSON.parse` алдаагүй), UTF-8.
- [ ] `pinyinNum` дотор аялгууны тэмдэг (āáǎà) **байхгүй**, зөвхөн үсэг + 1–5 тоо.
- [ ] `ü` бүгд `v` болсон.
- [ ] `meaningMn` дотор англи, орос үг байхгүй.
- [ ] Жишээ өгүүлбэр бүр хятадаар **утга агуулсан бүтэн өгүүлбэр**, орчуулга нь байгалийн монгол.
- [ ] `id` давхардаагүй, дугаарлалт нь заасан загвартай.
- [ ] Тоолуур үг, аялгууны хувирал шаардлагатай газарт бөглөгдсөн.
